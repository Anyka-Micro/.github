**Anyka Open Source** is Anyka's official home on GitHub for SDKs, tools and applications for the Anyka SoC family (AK3918 and others). Official releases are published here as they become available. The community projects we track are listed in **[awesome-anyka](https://github.com/Anyka-Micro/awesome-anyka)**, credited to their authors.

**Get started**

- Open firmware for supported cameras → [OpenIPC/firmware](https://github.com/OpenIPC/firmware)
- AK3918 cameras, from an SD card → [MuhammedKalkan/Anyka-Camera-Firmware](https://github.com/MuhammedKalkan/Anyka-Camera-Firmware) (actively maintained continuation: [kkrzysztofik/Anyka_ak3918_hacking_journey](https://github.com/kkrzysztofik/Anyka_ak3918_hacking_journey))
- AK39EV330 cameras → [michelostojski/akost-firmware](https://github.com/michelostojski/akost-firmware)
- Everything else → [awesome-anyka](https://github.com/Anyka-Micro/awesome-anyka)

> [!IMPORTANT]
> Community projects aren't supported by Anyka · check each project's license before you redistribute it · flashing custom firmware is at your own risk.
